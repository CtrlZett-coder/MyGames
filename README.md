# 🚀 MyGames

Коллекция игр, написанных на Python.

---

## Space Shooter

Горизонтальный космический шутер — уничтожай вражеские корабли, пока они не добрались до тебя!

### Управление

| Клавиши | Действие |
|---------|----------|
| `W` / `↑` | Вверх |
| `S` / `↓` | Вниз |
| `A` / `←` | Влево |
| `D` / `→` | Вправо |
| `Пробел` | Стрелять |
| `R` | Начать заново (после Game Over) |
| `Q` | Выйти |

### Враги

| Тип | Описание |
|-----|----------|
| 🔴 **Fighter** | Быстрый истребитель, 1 очко здоровья, 100 очков |
| 🟣 **Scout** | Очень быстрый разведчик, 1 HP, 150 очков |
| 🟠 **Heavy** | Тяжёлый крейсер, 3 HP, стреляет тройным залпом, 300 очков |

### Механика

- С каждым уровнем увеличивается частота появления врагов и их количество тяжёлых кораблей
- У игрока 3 жизни; после попадания — короткая неуязвимость (мигание)
- Уровень повышается каждые 10 убийств

### Запуск

```bash
cd space_shooter
pip install -r requirements.txt
python main.py
```
