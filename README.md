## Space Shooter

Горизонтальный космический шутер — уничтожай вражеские корабли, пока они не добрались до тебя!

### Управление

| Клавиши | Действие |
|---------|----------|
| `W` / `↑` | Вверх |
| `S` / `↓` | Вниз |
| `A` / `←` | Влево |
| `D` / `→` | Вправо |
| `Пробел` | Стрелять |
| `R` | Начать заново (после Game Over) |
| `Q` | Выйти |

### Враги

| Тип | Описание | HP | Очки |
|-----|----------|----|------|
| 🔴 **Fighter** | Быстрый истребитель | 1 | 100 |
| 🟣 **Scout** | Очень быстрый разведчик | 1 | 150 |
| 🟠 **Heavy** | Тяжёлый крейсер, тройной залп | 3 | 300 |

### Бонусы (Power-ups)

Выпадают из уничтоженных врагов со случайным шансом (Heavy — 45%, остальные — 20%).

| Иконка | Тип | Эффект | Длительность |
|--------|-----|--------|--------------|
| `2×` | Double Shot | Двойной выстрел (два потока пуль) | 10 сек |
| `SHD` | Shield | Поглощает одно попадание (щит вокруг корабля) | До удара |
| `SLW` | Slow Time | Замедляет всех врагов вдвое | 5 сек |
| `+HP` | Extra Life | +1 жизнь (максимум 5) | Навсегда |

### Звуки

Игра генерирует звуки **процедурно** через numpy (без аудиофайлов):
- 🔫 Выстрел — короткий высокий тон
- 💥 Взрыв — шумовой всплеск с затуханием
- 💔 Попадание — низкий удар
- ✨ Бонус — восходящий глиссандо
- 🛡 Щит сломан — особый звук
- 🎵 Фоновая музыка — атмосферный дрон-луп (синтез)

> Если `numpy` не установлен — игра работает без звука.

### Боссы

| Уровень | Босс | HP | Атаки | Награда |
|---------|------|----|-------|---------|
| 3, 6, 9… | 🟡 **Мародёр** (Marauder) | 8 | Веер из 6 пуль, синусоидальное движение | 1500 очков + 2 бонуса |
| 5, 10, 15… | 🔴 **Дредноут** (Dreadnought) | 25 | Фаза 1: залп из 7 пуль; Фаза 2: 9 пуль + **лазерный луч** | 5000 очков + 4 бонуса |

**Дредноут — Фаза 2** (ниже 40% HP):
- Экран вспыхивает красным (эффект «берсерк»)
- Ускоренный огонь, шире веер
- Периодический **лазерный луч** — полоса через весь экран
- В баре вверху появляется надпись `— PHASE 2 —`

Во время боя с **Дредноутом** обычные враги не спавнятся. С Мародёром — спавнятся (хаос!).

### Механика

- С каждым уровнем: враги спавнятся чаще, появляются Heavy-крейсеры
- У игрока 3 жизни; после попадания — короткая неуязвимость (мигание)
- Активные бонусы отображаются в левом нижнем углу с таймером
- Уровень повышается каждые 10 убийств
- Убийство босса засчитывается как несколько обычных убийств (Мародёр — 3, Дредноут — 6)

### Запуск

```bash
cd space_shooter
pip install -r requirements.txt
python main.py
```

## Побег (Escape)

Головоломка «сдвинь блоки» в духе Rush Hour / Unblock Me: перетаскивай блоки вдоль их оси, чтобы освободить путь розовому блоку к выходу. Поле 10×10 на всех уровнях.

Игра рассчитана только на телефон: вертикальная (portrait) ориентация, крупные кнопки под доской, собирается в отдельный APK (`android_escape/`) со своей иконкой.

Файл: `escape.html` (используется как исходник для APK; также открывается в браузере, но интерфейс оптимизирован под узкий вертикальный экран).

### Управление

Перетаскивание пальцем — блок двигается только вдоль своей оси (горизонтальные блоки — влево/вправо, вертикальные — вверх/вниз) и фиксируется на ближайшей свободной клетке в момент, когда палец отпускают. Кнопки «Отмена» / «Заново» / «Меню» — под доской.

### Сложность по уровням

Поле всегда 10×10. Каждая доска строится инкрементальным генератором (не входит в поставку): блоки добавляются по одному, и после **каждого** добавления реальный минимум ходов до решения пересчитывается настоящим A\*-солвером — никаких оценок и предположений. «Пар» — это честный, посчитанный компьютером минимум, а не длина случайной перестановки.

| Уровень | Блоков на доске | Реальный минимум ходов («пар») |
|---------|-----------------|----------------------------------|
| 1 | 2 | 2 |
| 2 | 7 | 4 |
| 3 | 12 | 7 |
| 4 | 19 | 11 |
| 5 | 24 | 16 |

Уровней пока 5, а не 10: честная проверка A\*-солвером на поле 10×10 быстро дорожает вычислительно (это по сути NP-трудная задача), и в разумное время получилось надёжно построить и проверить только эти пять — зато без единой придуманной цифры.

### Механика

- За решение уровня начисляются звёзды (1–3) в зависимости от того, насколько число ходов игрока близко к «пар»
- Есть отмена хода (история) и перезапуск уровня
- Прогресс, лучшие результаты по ходам и звёзды сохраняются в localStorage

### Android APK

Собирается автоматически через GitHub Actions (WebView-обёртка вокруг `escape.html`, проект `android_escape/`).
