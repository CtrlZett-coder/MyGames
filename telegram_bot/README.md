# Block Blast Solver — Telegram-бот

Подсказывает лучший ход для паззла Block Blast (поле 8x8, 3 фигуры за раунд,
очистка полных строк/столбцов). Поле и фигуры вводятся вручную через
инлайн-кнопки Telegram — распознавания скриншотов нет.

## Как это работает

- `pieces.py` — библиотека фигур (полимино). Базовые формы заданы один раз,
  все уникальные повороты на 90° генерируются автоматически.
- `solver.py` — поле хранится как 64-битная битовая маска. Для трёх выданных
  фигур перебираются все порядки установки и все позиции каждой, с
  симуляцией очистки линий после каждого хода. Лучший вариант выбирается по
  очкам, при равенстве — по «открытости» поля (больше свободных клеток,
  меньше изолированных дырок).
- `render.py` — текстовый/эмодзи-рендер поля и пошаговой схемы хода.
- `bot.py` — сам Telegram-бот на `python-telegram-bot`. Состояние (поле,
  выбранные фигуры) хранится в памяти по `chat_id` — переживает только до
  перезапуска процесса.

## Запуск

```bash
cd telegram_bot
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=<токен от @BotFather>
python bot.py
```

## Использование в Telegram

1. `/start` — приветствие и редактор поля.
2. Отметьте занятые клетки на сетке 8x8 (тап переключает ⬜/⬛) → «✅ Поле готово».
3. Выберите ровно 3 фигуры, которые выдала игра (страницы листаются ◀️▶️).
4. Бот посчитает лучший порядок и расположение и пришлёт схему ходов 1️⃣2️⃣3️⃣
   с указанием очищаемых линий и итоговым счётом.
5. «✅ Применить и продолжить» переносит получившееся поле в следующий раунд
   и сразу открывает выбор следующих 3 фигур.

## Набор фигур

Стандартный набор полимино (линии 1–5, квадраты 2x2/3x3, прямоугольник 2x3,
L/J/T/S/Z-тетромино, плюс-, уголок- и U-пентомино) — это приближение к
реальной игре. Если в вашей версии Block Blast фигуры отличаются, добавьте
их в `BASE_SHAPES` в `pieces.py`: формат — список относительных координат
клеток, повороты сгенерируются сами.

## Деплой

В репозитории есть `Dockerfile` (см. также `server/` для аналогичного
паттерна с Node.js). Соберите образ и задеплойте на любой хостинг с
постоянным процессом (Fly.io, Railway, VPS и т.п.), передав
`TELEGRAM_BOT_TOKEN` через переменную окружения:

```bash
docker build -t block-blast-bot .
docker run -e TELEGRAM_BOT_TOKEN=<токен> block-blast-bot
```

## Известные ограничения

- Без распознавания скриншотов — поле и фигуры вводятся руками через кнопки.
- Очки — эвристическая оценка для ранжирования ходов, не точная игровая шкала.
- Худший случай (3 разные мелкие фигуры на почти пустом поле) считается
  дольше обычного (несколько секунд) — это редкий и не критичный сценарий,
  бот в это время отвечает «🤔 Считаю варианты...».
