# Скачать Space Shooter

## 🌐 HTML5-версия (браузер, без установки)

**[SpaceShooter_HTML5.html](SpaceShooter_HTML5.html)** — нажми "Raw" → сохрани файл → открой в браузере.

Работает на телефоне и ПК. Без интернета после загрузки.

---

## 📦 Android APK

APK собирается автоматически CI и прикрепляется к **[Releases](../../../releases)**:

1. Перейди во вкладку **Releases** репозитория
2. Скачай `SpaceShooter.apk`
3. Установи: Настройки → Безопасность → Разрешить из неизвестных источников

---

## 🐍 Python-версия (запуск на ПК)

```bash
pip install pygame
python space_shooter/main.py
```
