# 📚 Репетитор — Telegram-бот

Присылаешь фото задания или пишешь его текстом. Бот объясняет по шагам, как его решать: какая тут тема, какое правило нужно и почему каждый шаг делается именно так. В конце он даёт похожую задачу для самопроверки и может проверить твоё решение.

## Что нужно

1. **Токен бота.** Напиши [@BotFather](https://t.me/BotFather) в Telegram, отправь `/newbot` и скопируй токен.
2. **Ключ Claude API.** Его можно получить на https://platform.claude.com (API платный, оплата за запросы). Если тебе нет 18, попроси взрослого.
3. Python 3.10 или новее.

## Запуск

```bash
cd homework_helper
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="токен от BotFather"
export ANTHROPIC_API_KEY="ключ API"
python bot.py
```

Бот работает, пока запущена программа. Ключи не коммить в git!

## Команды

| Что делаешь | Что происходит |
|---|---|
| `/start` | Приветствие |
| Фото задания (можно с подписью) | Подробный разбор |
| Текстовое сообщение | Вопрос по текущему заданию или новое задание текстом |
| `/new` | Начать новую тему |
