# 📚 Репетитор — Telegram-бот

Присылаешь задание (фото или текстом) — бот объясняет по шагам, как его решать: какая тема, какое правило нужно, почему каждый шаг делается именно так. В конце даёт похожую задачу для самопроверки и может проверить твоё решение.

Работает с **Claude** (по умолчанию) или с **DeepSeek**.

## Что нужно

1. **Токен бота** — напиши [@BotFather](https://t.me/BotFather) в Telegram, команда `/newbot`, скопируй токен.
2. **Ключ нейросети:**
   - DeepSeek — на https://platform.deepseek.com (API Keys + пополнить баланс), или
   - Claude — на https://platform.claude.com.
3. Python 3.10+.

## 🔑 Куда вписать ключи

Скопируй файл `.env.example` в `.env` (в той же папке) и впиши туда токен,
ключ и свой ID. Бот прочитает их сам, `export`/`set` не нужны.

**Никогда не вписывай ключи в `bot.py` или другие файлы, которые попадают
на GitHub!** Файл `.env` специально исключён из git (см. `.gitignore`).

## Запуск с DeepSeek

Сначала `export PROVIDER=deepseek`, затем:

```bash
cd homework_helper
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="токен от BotFather"
export DEEPSEEK_API_KEY="ключ DeepSeek"
python bot.py
```

⚠️ **Фото:** обычная модель DeepSeek (`deepseek-chat`) может не понимать картинки. Тогда бот ответит «перепиши задание текстом». Если у DeepSeek появится модель с поддержкой фото, укажи её: `export DEEPSEEK_MODEL="название-модели"`.

## Запуск с Claude (по умолчанию, понимает фото)

```bash
export ANTHROPIC_API_KEY="ключ Claude"
python bot.py
```

Бот работает, пока запущена программа. **Ключи не коммить в git!**

## Команды

| Что делаешь | Что происходит |
|---|---|
| `/start` | Приветствие |
| Фото задания (можно с подписью) | Подробный разбор |
| Текстовое сообщение | Вопрос по текущему заданию или новое задание текстом |
| `/new` | Начать новую тему |
| `/balance` | Сколько денег осталось |
| `/topup 300` | Записать, что пополнил баланс на 300 ₽ |
| `/topup =250` | Задать баланс точно (как показывает сайт) |
| `/myid` | Узнать свой Telegram ID |

## 💰 Учёт денег

После каждого ответа бот пишет, сколько стоил ответ и сколько осталось.
Когда остаётся меньше 50 ₽, он предупреждает.

Узнать баланс API автоматически нельзя, поэтому бот считает сам: берёт
число токенов из ответа и умножает на цену. Это **примерно**, точная сумма
видна на сайте. Поэтому:

1. Пополнил баланс на сайте, например на 300 ₽, → напиши боту `/topup 300`.
2. Иногда сверяйся с сайтом и поправляй: `/topup =точная_сумма`.

Настройки (необязательно):

| Переменная | Что значит | По умолчанию |
|---|---|---|
| `LOW_BALANCE_RUB` | Когда предупреждать | 50 |
| `USD_RUB` | Курс доллара | 100 |
| `PRICE_IN` / `PRICE_OUT` | Цена за 1 млн токенов, $ | по модели |

## 🔒 Доступ только для себя

Иначе кто угодно может найти бота и тратить твои деньги.
Напиши боту `/myid`, затем запусти так:

```bash
export ALLOWED_USERS="твой_ID"
```

Несколько человек можно через запятую: `"123,456"`.
